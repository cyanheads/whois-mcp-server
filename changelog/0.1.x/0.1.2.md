# 0.1.2 — 2026-06-06

## Changed

- **DoH fallback provider** switched from Google Public DNS to NextDNS (`https://dns.nextdns.io`) (#1). Google's terms restrict third-party relaying; NextDNS is terms-compliant, speaks the same `application/dns-json` format, returns human-readable CAA data, and is HTTP/1.1-compatible. `DnsLookupResult.source` and the `whois_get_dns` output schema updated: `'cloudflare' | 'nextdns'` (was `'google'`).
- **`whois_get_dns` description** — internal resolver routing details (IPs, CAA-routing rationale) removed; description now describes behavior only (#3).
- **`whois_lookup_domain` description** — replaced `"RDAP 404 (domain not registered) throws domain_not_found"` with implementation-neutral phrasing (#3).
- **`whois_check_availability` description** — removed `"RDAP 404 = available"` implementation detail; output now states behavior plainly (#3).

## Fixed

- **`whois_lookup_domain` — `domain_not_found` now includes `recovery.hint`** (#2). The service-layer `notFound()` factory bypassed the typed error contract; handler now intercepts and re-throws via `ctx.fail('domain_not_found', …)` with `ctx.recoveryFor()`, so `data.recovery.hint` is populated for agents.
- **`whois_check_availability` — dead `rdap_no_coverage` error contract removed** (#4). The no-coverage case returns `{ available: null, rdap_coverage: false }` as data, never throws. The dead contract entry implied an error path that does not exist.

## Dependency bumps

- `@types/node` `^25.9.1` → `25.9.2`
