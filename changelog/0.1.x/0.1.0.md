# 0.1.0 — 2026-06-04

## Added

- **`whois_lookup_domain`** — domain registration lookup via RDAP with IANA bootstrap; returns registrar, dates, nameservers, EPP status, DNSSEC flag, registrant org.
- **`whois_check_availability`** — domain availability check; RDAP 404 = available (data path, not error).
- **`whois_get_dns`** — multi-type DNS record lookup via DNS-over-HTTPS (Cloudflare primary, Google fallback); supports A, AAAA, MX, TXT, NS, CNAME, SOA, CAA, PTR. CAA uses Google DoH (Cloudflare returns raw hex).
- **`whois_lookup_ip`** — IP/CIDR netblock lookup via RIR RDAP (IANA bootstrap auto-routes to ARIN/RIPE/APNIC/LACNIC/AFRINIC); includes PTR reverse DNS via DoH.
- **`whois_lookup_asn`** — ASN resolution via RIR RDAP.
- **`whois_get_dossier`** — one-call domain triage: RDAP + DNS in parallel with inferred ns_provider and mx_provider signals; partial results on single-leg failure.
- **`rdap-service`** — IANA bootstrap cache (24h TTL), domain/IP/ASN RDAP lookups with retry.
- **`doh-service`** — DoH fetch with Cloudflare/Google failover and retry.
- **`server-config`** — env vars for RDAP/DoH timeouts and retry limits.
