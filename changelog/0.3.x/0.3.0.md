# 0.3.0 — 2026-11-11

## Added

- Add the whois-guide skill resource for registration, DNS and routing investigations. Read it at `skill://whois-guide/SKILL.md`.
- **Domain inputs** accept Unicode names and return optional `unicode_domain` alongside the ASCII lookup name. ([#40](https://github.com/cyanheads/whois-mcp-server/issues/40))
- **`whois_get_dns`** supports SRV, DS, DNSKEY, TLSA and HTTPS records with literal resolver presentation. ([#39](https://github.com/cyanheads/whois-mcp-server/issues/39))
- **IP and ASN lookups** return optional `registration_date` and `last_changed` from the queried RDAP object. ASN lookups also return `abuse_email` when present. ([#38](https://github.com/cyanheads/whois-mcp-server/issues/38))

## Changed

- **`whois_get_dossier`** can query the ICANN registrable parent after an exact registry 404 and identify it in `registration_domain`. DNS stays on the queried name. ([#35](https://github.com/cyanheads/whois-mcp-server/issues/35))
- **`whois_lookup_domain`** names the registrable parent after an exact miss and points to DNS evidence when the suffix lacks RDAP coverage. ([#35](https://github.com/cyanheads/whois-mcp-server/issues/35), [#37](https://github.com/cyanheads/whois-mcp-server/issues/37))
- **Packaging and tooling** add root Agent Plugins metadata, tighten MCPB exclusions and sync framework validation and release tooling.
- **Bun** requires 1.4.4 or newer. The container image uses Bun 1.4.4.

## Fixed

- **RIPE IP and ASN lookups** use direct organization evidence and omit `org_name` when absent. IP and ASN country codes use uppercase when supplied. ([#34](https://github.com/cyanheads/whois-mcp-server/issues/34))
- **Dossier provider labels** use the registrable label for unmatched NS and MX hosts, including hosts under multi-label suffixes. ([#36](https://github.com/cyanheads/whois-mcp-server/issues/36))
- **Domain validation** rejects malformed A-labels before lookup and rejects URL-shaped registry identities. ([#40](https://github.com/cyanheads/whois-mcp-server/issues/40))
