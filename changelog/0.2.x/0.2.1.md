# 0.2.1 — 2026-10-16

## Added

- **`whois_lookup_ip`** accepts optional `include_routing` for separately attributed RIS prefix/origin ASN observations, bounded to one 3000 ms request; optional failure retains registry and PTR data. ([#32](https://github.com/cyanheads/whois-mcp-server/issues/32))

## Fixed

- **`whois_get_dossier`** preserves null MX `0 .` and labels explicit no-mail service without assigning a provider. ([#28](https://github.com/cyanheads/whois-mcp-server/issues/28))
- **`whois_get_dns`** retains supported NXDOMAIN answer records and resolver provenance, including aliases preceding a missing terminal name. ([#29](https://github.com/cyanheads/whois-mcp-server/issues/29))
- **Primary domain RDAP** rejects malformed, error and mismatched objects before reporting registration; sparse matching identities remain accepted and dossiers retain successful DNS. ([#30](https://github.com/cyanheads/whois-mcp-server/issues/30))
- **RDAP presentation** renders provider punctuation and whitespace literally across domain, dossier, IP and ASN results, including registrar detail. ([#31](https://github.com/cyanheads/whois-mcp-server/issues/31))
- **MCPB packaging** excludes project tests and fixtures.
